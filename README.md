# Meu Financeiro

Dashboard responsivo para um sistema pessoal de organização financeira. O projeto está sendo desenvolvido em etapas, começando pela estrutura e interface.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta `FinanceHelper` no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador. Se tiver a extensão Live Server, você também pode clicar com o botão direito no arquivo e selecionar **Open with Live Server**.

## Estado do projeto

A interface do dashboard usa números e movimentações fictícias apenas para demonstrar o layout. Nesta etapa, os dados não são armazenados e os botões de funcionalidades futuras permanecem desativados.
